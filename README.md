# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 实训中断补偿

自然灾害或企业停产会使一批学生的实训中断。服务支持完整的中断补偿闭环（均位于 `/api/plans/{plan_version}` 下）：

1. **中断登记**：`POST /interruptions` 登记中断窗口（原因、起止时间，状态为 ACTIVE）。
2. **影响名单**：`POST /interruptions/{id}/impacts` 批量导入受影响学生、原活动、能力（技能）要求、原排期与已完成签到区间；服务按中断窗口与排期求交计算能力缺口，已完成部分从缺口中扣除（避免重复计入）但保留来源登记。
3. **替代目录**：`PUT /catalog` 维护替代活动（技能编码、折算权重）与共享可用时段（容量）。
4. **方案生成**：`POST /interruptions/{id}/compensations/generate` 按能力要求匹配替代活动、绕开学生既有签到忙碌时段、按窗口容量批量生成补偿排期；替代学时按权重折算为原活动学时，结果确定且幂等。
5. **学生确认**：`POST /compensations/{code}/confirm` 基于版本号乐观锁定，并发确认只有一个成功，锁定后不可改期。
6. **调整**：`PATCH /compensations/{code}/slots/{slot_id}` 支持确认前改期（校验目标窗口容量并迁移名额）；`POST .../complete` 登记确认方案中时段的实际完成情况。
7. **重启恢复**：`POST /interruptions/{id}/resume` 在原活动恢复时只释放恢复时刻尚未开始的补偿时段并归还名额，已开始/已完成部分保留来源。
8. **结算**：`POST /interruptions/{id}/settle` 汇总每个学生的缺口、补偿完成折算学时与原活动保留来源；未确认方案不产生补偿学时。

容量按“方案占用窗口”计数：同一方案在同一窗口的多个分段只占一个名额，不同方案分别计数，生成与确认均通过条件更新保证并发安全。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。
